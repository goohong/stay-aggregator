# 숙박 상품 통합 연동

## 무엇을 하는가

여러 숙박 공급사의 서로 다른 API 를 하나의 표준 모델로 통합한다. 공급사의
숙소 목록을 받아 내부 식별자로 매핑해 두고, 고객이 날짜와 인원으로 검색하면
공급사에 병렬로 재고·요금을 물어 정규화한 뒤 하나의 결과로 합쳐 돌려준다.
공급사 하나가 실패해도 나머지 결과로 응답한다.

## 오픈 질문

| # | 질문 | 후보 |
|---|---|---|
| Q1 | 금액을 표준 모델에서 어떻게 표현할지 (통화, 세금 포함 여부, 최소 단위) | 세금 포함 총액을 필수 필드로, 원본이 준 부가 정보(날짜별 단가, 세금 분리액)는 nullable 로 보존. 공급사별 원본은 sealed interface 로 어댑터 안에 가둠 |
| Q2 | 날짜·숙박 구간을 어떻게 표현할지 | |
| Q3 | 재고를 어떤 단위로 저장하고 판정할지 | |
| Q4 | 판매 조건(조식 포함 여부 등)을 어느 계층에 둘지 | |
