# 숙박 상품 통합 연동

## 무엇을 하는가

여러 숙박 공급사의 서로 다른 API 를 하나의 표준 모델로 통합한다. 공급사의
숙소 목록을 받아 내부 식별자로 매핑해 두고, 고객이 날짜와 인원으로 검색하면
공급사에 병렬로 재고·요금을 물어 정규화한 뒤 하나의 결과로 합쳐 돌려준다.
공급사 하나가 실패해도 나머지 결과로 응답한다.

## 오픈 질문

| # | 질문 | 상태 |
|---|---|---|
| Q33 | 임시값(타임아웃·검색 한계·동시 실행 수·재시도 대기·서킷 기준·격리 보관 기간)을 근거로 정하기 | 방법은 정함(외부 근거 + 측정). 조사 끝, 값 결정 전 |
| Q34 | 동일 숙소 구현 (ADR-0058) | 결정 끝, **구현 전** |
| Q35 | 요금·재고 캐시 구현 (ADR-0065) | 결정 끝, **구현 전**. 구현할지 다시 정한다 |
| Q36 | API 문서 자동화 구현 (ADR-0063) | 결정 끝, **구현 전** |
