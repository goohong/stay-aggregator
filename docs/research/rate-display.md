# 숙박 요금 표시와 요금 조건 조사

요금 표준 모델을 정할 때 "무엇을 기준값으로 삼고, 어떤 조건을 요금에 붙일지"의
근거로 조사했다. 여기에는 확인한 사실만 적고, 판단은 해당 ADR 에 적는다.

각 사실 옆의 **원문** 링크는 출처 페이지에서 해당 문장으로 바로 이동한다. 섹션 앵커가 있는 페이지는 앵커도 함께 적었다.

## 요약

- 규제(한국·미국)와 플랫폼 세 곳 모두 **숙박 기간 전체 총액**을 기준으로 삼거나 가장 눈에 띄게 보여준다
- **1박 가격의 정의는 플랫폼마다 다르다.** 세금 포함 총액을 박수로 나눈 곳과, 세금 제외 1박 가격으로 보이는 곳이 있다
- 요금에 붙는 조건으로 **조식 포함 여부와 무료 취소**가 공통으로 쓰인다. 식사를 종류로 나누는 곳도 있다
- 한 객실 타입에 **요금이 여러 개** 붙는다(판매 조건·할인 방식이 다른 요금)
- "세금 포함" 총액이어도 **현장에서 추가로 내는 세금·요금**이 있을 수 있다

## 2. 플랫폼 화면

조회 조건: 오사카, 2026-10-13 체크인 ~ 10-16 체크아웃(3박), 객실 1, 성인 2. 조회일 2026-09-14.
검색 화면의 금액은 **조회 시점 값**이라 다시 열면 달라진다.

| | 크게 보이는 값 | 함께 보이는 값 | 요금 조건 필터 |
|---|---|---|---|
| 국내 대형 숙박 플랫폼 (해외숙소) | 1박 가격 | 총 3박 금액 (세금 포함) | 무료취소, 조식포함 |
| Trip.com | 1박 가격 | Total price, 3박, 세금·수수료 포함, "Additional charges may apply" | 조식 포함, 무료 취소 / 식사: 조식·석식·조식+석식 / 결제: 선결제·현장결제 / 연박 할인 |
| Airbnb | 총액 (2025-04-21 보도, **모든 사용자** 기본) | 수수료 포함, 세금은 지역에 따라 포함 | 조회 안 함 |

### 국내 대형 숙박 플랫폼
- 목록의 1박 가격은 **세금 포함 총액을 박수로 나눠 반올림한 값**이다. 세 숙소에서 계산이 맞았다 (310,328 ÷ 3 = 103,442.67 → 103,443)
- 가격 필터의 이름은 "1박 가격"이다
- 숙소 상세에서 **같은 객실 타입 아래 요금이 여러 개** 있다. 예: 같은 더블 룸에 "임박 할인 · 룸온리"와 "3연박 할인 · 룸온리"가 다른 가격으로 있음
- **요금마다** 무료 취소 기한(날짜·시각), 조식 포함 여부, "세금 및 봉사료 포함"이 붙는다
- 판매자 정보가 객실(요금)별로 다르다고 안내한다
- 일본 숙박세는 체크인 시 현장에서 따로 청구될 수 있다고 공지한다
- 출처: 직접 조회 (주소 생략)

### Trip.com
- 2026-09-14 조회 때 카드의 1박 가격(US$40)이 총액 ÷ 박수(US$133 ÷ 3 = 44.3)와 달랐다. 2026-09-15 재대조 때 같은 숙소 총액은 US$132 였다
- 가격 필터 이름이 "Price per room per night (excl. taxes & fees)" 여서 **세금·수수료 제외 1박 가격으로 보인다** (필터 이름으로 추정) — [원문](https://www.trip.com/hotels/list?city=219&checkin=2026-10-13&checkout=2026-10-16&adult=2&crn=1#:~:text=Price%20per%20room%20per%20night%20%28excl.%20taxes%20%26%20fees%29)
- 총액 아래에 "Additional charges may apply" 가 붙는 숙소가 있다 — [원문](https://www.trip.com/hotels/list?city=219&checkin=2026-10-13&checkout=2026-10-16&adult=2&crn=1#:~:text=Additional%20charges%20may%20apply)

### Airbnb
- 검색 결과부터 수수료와 (지역에 따라) 세금을 넣은 전체 가격을 **모든 사용자**에게 기본으로 보여준다. 이전에는 1박 요금 기준 표시였다 — [전체 가격](https://www.cnn.com/2025/04/21/business/airbnb-total-pricing#:~:text=All%20users%20will%20now%20see%20the%20full%20price%20of%20a%20stay) · [1박 기준에서 바뀜](https://www.cnn.com/2025/04/21/business/airbnb-total-pricing#:~:text=a%20change%20from%20displaying%20prices%20based%20off%20the%20nightly%20rate)
- 확인 경로는 언론 보도(CNN)이며, 회사 공식 발표문은 직접 확인하지 못했다. 기사에 "전 세계"라는 표현은 없다

### 확인하지 못한 곳
- 야놀자(NOL) 해외숙소: 검색 입력이 반영되지 않아 요금 화면까지 가지 못했다
