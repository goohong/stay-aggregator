# 0003. CLAUDE.md 를 저장소에 공개

## Context

이 프로젝트는 코드를 AI 와 함께 작성한다. `CLAUDE.md` 는 그 작업 규칙을 담는 파일이고,
저장소에 둘지 `.gitignore` 로 뺄지 정해야 한다.

## Options

- **(가) 저장소에 둔다** ← AI 추천 — 어떤 규칙으로 작업했는지가 코드와 함께 버전 관리된다.
  규칙이 바뀐 시점도 이력에 남는다. 대신 작업 지시 문서가 저장소에 드러난다.
- **(나) `.gitignore` 로 뺀다** — 저장소가 결과물만 담는다.
  대신 작업 규칙이 남지 않아 나중에 "왜 이렇게 일했는지"를 알 수 없다.

## Decision

**(가)** 저장소에 둔다. 단 두 가지를 지킨다.

- **사람이 읽어도 말이 되는 규칙 문서로 쓴다.** AI 에게 던지는 명령문 투로 쓰지 않는다
- **작업 절차만 담는다.** 코드나 문서의 품질을 주장하는 문장은 쓰지 않는다.
  작업 지시 문서가 할 일이 아니다

이 파일을 공개한 이유는 README 에 한 줄 밝힌다.

**이유** — 어떤 규칙으로 AI 와 일했는지가 결과물의 일부라고 본다.

## Consequences

**얻는 것**
- 작업 규칙이 코드와 같은 이력을 갖는다. 규칙을 바꾼 시점이 커밋으로 남는다

**잃는 것**
- 규칙을 고칠 때마다 커밋이 하나씩 늘어난다

## Verification

`CLAUDE.md` 가 저장소에 있고, README 에 공개 이유가 적혀 있는지.
