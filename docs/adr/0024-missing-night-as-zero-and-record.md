# 0024. 숙박일이 빠진 재고 응답은 그 날을 0 으로 보고 사실을 남기기로 결정

## Context

연박 예약 가능 객실 수는 숙박일별 잔여 수의 최솟값으로 판정한다([ADR-0023](0023-multi-night-availability-minimum.md)).
두 공급사의 스펙은 날짜별 재고가 체크인일부터 체크아웃 전날까지 모두 온다고 정한다. 매진은 그 날짜 항목이 `remainingRooms: 0` 으로 오는 것이다.

스펙은 날짜 항목 자체가 빠진 응답을 언급하지 않는다. 그런 응답이 오면 규약과 다르다는 사실만 알 수 있고,
원인(공급사 쪽 결함, 응답 일부 유실, 규약 변경 등)은 응답만으로 알 수 없다.
따로 정하지 않으면 최솟값 계산은 있는 날짜만 보게 되어, 재고를 모르는 날이 있는데도 예약 가능으로 판정한다.

## Options

- **(가) 빠진 날을 0 으로 보아 그 객실 타입을 예약 불가로 판정** — 모르는 날을 팔지 않는다. 대신 고객에게는 매진과 같은 결과로 보인다.
- **(나) 그 객실 타입을 응답에서 뺌** ← AI 추천 — 매진과 섞이지 않는다. 대신 실제로는 방이 있었을 수도 있는 상품이 보이지 않는다.
- **(다) 있는 날짜만으로 최솟값 계산** — 따로 대비하지 않으면 이렇게 된다. 재고를 모르는 날을 팔 수 있다고 보여 준다.

## Decision

**(가)** 를 택한다. 요청 숙박일 중 응답에 없는 날은 잔여 수 0 으로 보고, 그 결과 예약 가능 객실 수는 0 이 된다.
날짜 항목이 빠진 응답을 받았다는 사실을 남긴다. 어떤 종류로 나눠 어떤 형태로 남길지는 Q17·Q18 에서 정한다.

**이유** — 재고를 모르는 날을 팔 수 있다고 보여 주지 않는 것이 먼저다. 규약과 다른 응답의 원인은 검색 중에 알 수 없으므로,
검색 경로에서는 보수적으로 판정하고 사실을 남겨 모니터링에서 알아채게 한다. 어긋남과 매핑에 없는 객실 타입을 다룬 방식
([ADR-0014](0014-detect-drift-in-search-correct-in-sync.md), [ADR-0015](0015-exclude-unmapped-room-types.md))처럼 검색은 판정만 하고, 기록의 형태는 모니터링 설계에 맡긴다.

## Consequences

**얻는 것**
- 재고를 모르는 날이 있는 객실 타입을 예약 가능으로 노출하지 않는다
- 판정 규칙(최솟값)은 그대로 두고, 빠진 날을 0 으로 채우는 한 단계만 더한다

**잃는 것**
- 검색 응답만 보면 규약과 다른 응답과 진짜 매진이 구분되지 않는다. 구분은 남긴 기록에서만 할 수 있다
- 남기기만 하고 아무도 보지 않으면 원인을 찾지 못한다

**의존**
- 예약 가능 객실 수가 0 인 상품을 응답에서 뺄지 0 으로 노출할지(Q7)에 따라 고객에게 보이는 모습이 달라진다
- 무엇을 어떤 형태로 남기고 누가 알아챌지(Q17·Q18)

**넘기는 것**
- 범위 밖 날짜, 같은 날짜 중복, 음수 잔여 수(Q24 의 나머지)

## Discussion

- **AI 주장과 근거** — 매핑에 없는 객실 타입을 응답에서 빼기로 한 ADR-0015 와 같은 방식으로 (나)를 권했다.
  (가)의 약점을 "공급사 오류가 매진과 구분되지 않는다"고 설명했다
- **반박** — 그날만 숙소 사정으로 방이 없는 특수 상황을 말하는 건가. 공급사 오류인지 어떻게 아나.
  0 으로 보고 사실은 남겨 모니터링하는 것이 맞고, 이전에 비슷하게 정한 방식대로 하면 된다
- **검증 결과** — 숙소 사정으로 방이 없는 날은 `remainingRooms: 0` 으로 오는 정상 매진이라 이 질문과 무관했다.
  원인이 공급사 오류라는 표현도 과장이었다. 응답만으로는 규약과 다르다는 사실만 알 수 있다
- **그래서 어떻게 바뀌었나** — 질문을 "날짜 항목이 빠진 규약 위반 응답"으로 좁혀 다시 물었고, 사용자 판단대로 (가)와 사실 기록으로 정했다

## Verification

재고 정규화 테스트에서 3박 요청에 날짜 항목이 둘만 온 응답이 예약 가능 객실 수 0 으로 판정되고, 빠진 날짜를 남기는지. 테스트를 만들면 그 이름을 여기에 적는다.
